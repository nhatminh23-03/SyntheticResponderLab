## C. Dr. Wang's five kickoff questions — answers found

1. **GitHub link / LICENSE / open-licensing for CARLE** — **There is no LICENSE or COPYING file anywhere in the repository.** Part of the runtime also lives in a third-party repo (`ytun1/NeoSmart-Hackathon-App`) — see F-01. Both must be resolved before deposit.
2. **Cost per study / accounts needed** — OpenRouter (required for any live run), Google Cloud Vision (optional, image analysis only). No built-in cost estimator exists. Cost is driven by the number of LLM **requests**: Split `N`, Mirror `N×M`, Stability `N×R`; plus 1 insights call per run, and ~`2N + N` for live interviews.
3. **Which parts were staged/shortcut** — Neo interview transcripts, themes, and grounding are **fixtures** (F-07). Persona "grounding" is heuristic, not census-based (baseline §6). The realism scorecard has no real target data (baseline §7).
4. **Group conversation instead of one-on-one** — not currently a feature; interviews are per-persona.
5. **What a new person needs to run it from scratch** — currently a broken answer: a fresh clone does not produce a runnable app (F-01), and the documented local setup migrates the wrong database (F-03).
